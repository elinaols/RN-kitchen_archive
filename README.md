# Kitchen Archive - React Native, Expo, Express

A school project built with React Native where I fetched recipes from a custom API and let users create, edit and delete recipes in the database, while saving favorite recipes locally using AsyncStorage. This project demonstrates my understanding 
of handling asynchronous API calls, performing full CRUD operations, managing state in React Native and persisting data locally.

# Features
- Fetch, create, edit and delete recipes from a custom API
- Save favorite recipes locally using AsyncStorage
- Demonstrates handling of asynchronous API calls and full CRUD operations
- Manage state efficiently in React Native

# Skills
- React Native
- Expo
- AsyncStorage
